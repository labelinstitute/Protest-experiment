# Protest-experiment
Code for a behavioral field experiment examining how allocation procedures affect legitimacy, collective action, and protest participation.
Protest Experiment. This repository contains the code for a behavioral field experiment examining collective action, perceived legitimacy, fairness, and protest participation. The project was developed through the Los Angeles Behavioral Economics Laboratory (LABEL) at the University of Southern California and implemented with university students in Madagascar.

# Research Design

Participants make decisions in groups composed of two leaders and twelve citizens. Across eight rounds, citizens decide whether to participate in a collective action. The action succeeds when at least eight of the twelve citizens participate.

The experiment compares three mechanisms for assigning leadership positions and allocating resources:

Merit: leadership positions are assigned according to performance.

These treatments allow the study to examine how the process used to assign authority influences perceived legitimacy, expectations, and willingness to participate in collective action.

Each treatment folder contains its corresponding oTree project files, including the Python experiment logic, HTML templates, and supporting static files.
